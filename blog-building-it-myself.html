I rebuilt what already existed, and I'd do it again

In November 2025 I started building my own IDE. Months later I found an open-source project that already had most of it. Here's why that wasn't wasted work — and what I'm changing from here.

Salman Ansari
29 April 2026 · 4 min read

In November 2025 I started building my own IDE, called Yavin. I used the Monaco Editor as the base and slowly turned it into a complete development tool, adding things one by one:

  • Git integration
  • A terminal
  • A file manager
  • And the other core features that make coding easier without switching between apps

At that time the goal was simple: understand how everything works by building it myself.

Then I found the thing that already did it

Yesterday I came across an open-source project that already has most of these features built in.

The first feeling was the obvious one — that I'd done extra work for nothing. That feeling lasted about as long as it took to look at the code.

✓
Building it myself helped me understand the system much better. I now know how these pieces actually connect and work behind the scenes — which is a different kind of knowledge from knowing that a library exists.

Reading someone else's editor architecture is a completely different experience when you've already fought the same problems. The file watcher, the terminal multiplexing, the way a diff view has to reconcile with an open buffer — I don't have to take those designs on faith. I know why they're shaped that way, because I got them wrong first.

What changes from here

Going forward I want to focus on:

  • Improving the architecture rather than widening the feature list.
  • Making it faster — the work that actually differentiates the tool.
  • Using open-source tools where it makes sense, instead of rebuilding everything.

That last line is the real shift. Rebuilding everything was the right call when the goal was learning. It's the wrong call now that the goal is a tool people use — and the agent layer, not the editor chrome, is where Yavin is actually worth building.

Still working on Yavin, and learning a lot through the process.
