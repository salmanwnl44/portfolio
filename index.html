Yavin

under development

An AI code editor where developers write, test and review code in one place. Suggestions draw on the user's own codebase rather than generic examples, and every AI change lands in a side-by-side review screen, so the developer stays in control of what gets accepted.

  • Built-in test panel to find, run, stop and inspect tests without leaving the editor.
  • Secure Rust + Tauri execution engine that blocks unsafe commands and any file access outside the project.
  • Dependable runs: time limits, clean cancellation, crash handling — verified by 58 automated tests.
