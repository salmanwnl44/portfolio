Yavin

GitHub

An AI code editor where developers write, test and review code in one place. Suggestions draw on your own codebase rather than generic examples, and every AI change lands in a side-by-side review screen so you stay in control of what gets accepted.

  • Built-in test panel: find, run, stop and inspect tests without leaving the editor.
  • Secure Rust + Tauri execution engine that blocks unsafe commands and any file access outside the project.
  • Dependable runs: time limits, clean cancellation and crash handling, verified by 58 automated tests.
